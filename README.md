# UI playground

Self-built, fun UI components kept as standalone pieces. Each folder has CSS, JS and an `index.html` demo (open directly in a browser).

- `bookmark-pill/` - bookmark flag folds into a box, a sheet drops in, unfolds blue, count rolls. After @turaluix "bookmarked. variant 2". Source of the frames: https://x.com/turaluix/status/2080720630534865182. Not wired into any product; was briefly the Wayfinder new-tab pin button. CSS is a hand-timed approximation (fake 3D). Not yet visually verified in a browser.
